# 独立预警换色 v1.0.0-beta7 · 铜金半亮度实验版

无需 UE4SS。此包与当前本机安装的 copperhalf 候选文件一致，单独提供预警换色，不包含卸势功能。

## 当前改动
- 保留红色卸势预警、黄色闪避光圈和简体中文教学提示。
- 三个 Glow_001 渲染层使用正确编码的颜色参数，RGB 为 (0.32, 0.04, 0)，透明度保持 0.75。
- 仍暂时关闭 15 个 Glow_010/Glow_011 渲染层，用于隔离横向白光；因此不是完整原版特效。

## 验证与限制
已完成容器检查、三种金黄预警资源打包读回逐字节比对，以及安装文件 SHA256 校验。
上一版铜金色外围已生效，但中心仍有白线；本版将该配比亮度减半，尚未获得有效实机战斗样本。两次窗口抓帧疑似停留在缓存画面，不能作为通过依据。暗金闪光、全部战斗场景与性能尚未验证。本版为实验预发布，不代表白光问题已解决。

## 安装
退出游戏，将压缩包完整解压到游戏目录以外，运行“安装.cmd”。也可把 ProjectPBZ 文件夹合并至游戏根目录，安装位置为 ProjectPBZ/Content/Paks/~mods/PBZWarningColors 下的三个同名文件。替换旧版本后重启游戏。

运行“卸载.cmd”归档本包并恢复安装前同名文件。不要同时启用旧 Lua 换色脚本。本包不安装或修改 UE4SS。可能与覆盖相同预警资源或简体中文 Game.locres 的模组冲突。
